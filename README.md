# Hangman Game 🪢

A classic **Hangman game** implemented in Python. Test your guessing skills and try to save the stickman from being hanged!  

This is a console-based game where you guess the letters of a randomly selected word. You have **6 lives** to guess the word correctly. Fail, and the hangman meets his fate! 😅

---

## Features

- Randomly selects a word from a predefined list.
- Shows the hangman progress with each wrong guess.
- Interactive console input for guessing letters.
- ASCII art for the hangman and stylish game introduction.
- Fun and engaging for all ages.

## Installation

1. Make sure you have **Python 3** installed on your system.
2. Clone this repository:

```bash
git clone https://github.com/Yuvraj-Malik/Hangman_Game.git
```
3. Navigate to the Code file:
```bash
cd [Your-Clone-Location]
```
4. Run the code:
```bash
python hangman.py
```
